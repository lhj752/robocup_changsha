## 1. 物理模型核对（决定后续全部设计的前提）

**问题**：10 步回合里机器人到底能移动多远？

**过程**：先按 `coverage_bench/envs/physics.py` 的欧拉积分推导，得到 10 步位移
0.638375；但用真实场景实测只有 **0.249010**，两者矛盾。

**根因**：`create_scenario`（`coverage_bench/envs/scenario.py`）会构造并锁定
`mpe_world`，因此正式路径走 **MPE2 的 `World.integrate_state`**
（`mpe2/_mpe_utils/core.py:231-252`），`physics.py` 的简化欧拉分支在生产环境中
从不执行。MPE2 的递推是

```
p_{k+1} = p_k + v_k * dt
v_{k+1} = (1 - damping) * v_k + (force/mass) * dt * a_k      # 先衰减、再加力
```

即速度每步增量是 `ca = 0.1`，且衰减发生在加速度之前。从静止出发 n 步的净位移按
**迭代**求得（位置先用旧速度，n 步只累加 n 项速度，第 1 步位移恒为 0）：

```
disp(1)=0  disp(2)=0.010000  disp(5)=0.077969  disp(10)=0.249010
```

**结论**：目标覆盖半径 0.15，因此只有初始距离大致在 0.35~0.40 以内的
机器人-目标对才可能形成覆盖。这决定了整个任务的性质是"极小位移预算下的近距离拦截"。

## 4. 修订 R1：上界判据的更正与命中点规划

### 4.1 触发点

复核时发现 E009 的上界工具把"n 步可达位移"当成**各向同性标量** `s_k`，
即判据 `|d| <= s_k + r_t`。但 MPE2 的控制约束是**逐分量**单位盒
（代码里直接 `v += (force/mass)*dt`，无范数归一），因此 k 步可达集是一个
**zonotope**，沿轴向支撑值是 `s_k`，沿对角是 `√2·s_k`。

### 4.2 判据对账（E022 的前置分析）

在同一批 (i,j,k) 上并排计算四个判据，并用 MPE2 真实积分回放：

| 判据 | 形式 | 公开套件 score | 判定 |
| --- | --- | --- | --- |
| A | `\|d\| <= s_k + r_t` | 191.67 | 低估 |
| C | `\|d\| <= s_k*(\|cosφ\|+\|sinφ\|) + r_t` | 241.67 | 高估 |
| **H** | **`√(max(0,\|d_x\|-s_k)² + max(0,\|d_y\|-s_k)²) <= r_t`** | **225.00** | **精确** |

- A 与 H 在 40000 组随机 (d,k) 上 2.8% 不一致；C 与 H 有 1.4% 不一致。
- **回放验证**：C 与 H 的分歧只有 3 个组合（`basic-0 (2,0,8)`、`coop-1 (0,2,3)`、
  `coop-1 (1,0,5)`）。按 H 的最优控制回放，实际最小距离为
  **0.1628 / 0.1508 / 0.1545**，均 `> r_t = 0.15`。故 C 高估，H 正确。
- H 的推导关键：`r_t` 是欧氏球；`|d| - r_t` 的单位球恰好是 `(|d_x|,|d_y|)` 的
  **l∞ 盒**，因此缺口必须用 l∞ 形式，不能把 `r_t` 各分量都加一遍。

**E022 是一个重要的负结果**：单纯把判据改对，**逐种子逐位相同**（298/300 平局）。
原因是原定稿的**控制律**是"朝目标单位方向满推力"，它到不了那些"对角可达"的点——
判据放宽了但动作跟不上。收益全部来自**控制律**（E024）与**命中点规划**（E025），
而不是可达判据本身。

**E026 被否决**：预测式避碰把碰撞回合从 23 提到 24（1000 回合口径），未达目的。

## 5. 已知局限

1. **公开成绩 221.67 不可外推**：公开套件只有 4 个场景，样本极小。
   留出集点估计 **157.19**，核验成绩应以 157 上下预期。
2. **约 1/4 场景上界本身为 0**（留出集 H 口径：uniform 23.6%、crossing 27.0%），
   任何策略都拿不到分。
3. **碰撞率高于原定稿**（i.i.d.500：93/1000 回合 vs 66/1000）。碰撞项代价约 1.5 分，
   覆盖增益约 +18.6 分，净收益明确。E026 的启发式尝试失败，正确方向是解析消解
   （对每个队友求使 `|Δp'| >= 0.10` 可行的控制区间，再投影到该区间）。
4. **上界是位置松弛**：撤掉了"必须存在一条同时满足全部各步约束的控制序列"这一要求，
   故仍可能高于真实可达值。留出集上 H 上界 164.83 与实测 157.19 之间剩 7.64 分。
5. **速度外推窗口**：目标每 5~10 步改向；`k*` 较大时外推误差上升，当前未加保守惩罚。
